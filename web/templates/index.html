安全靶场与加固对照平台

同一个业务，两套实现：安全实现用于跑通完整业务链路， 靶场实现故意保留 SQL 注入、存储型 XSS、CSRF、越权、无锁定登录五类典型漏洞， 供你复现、定位、修复，并在审计日志里留下痕迹。

{{if .Session}} 进入业务系统 进入靶场 {{else}} 登录 注册账号 {{end}}

分层架构

handler → service → store 三层，中间件链统一处理 request_id、日志、恢复、会话、CSRF、限流。

服务端会话

Redis 存储会话，Cookie 只放 256 bit 随机 ID；登录与改密时轮换会话，防会话固定。

审计可追溯

每条关键操作写入 audit_log，带 IP、UA、request_id，能与访问日志逐条对账。

可部署

支持 Docker Compose 一键起 MySQL + Redis + App，也提供裸机 systemd + Nginx 方案。
